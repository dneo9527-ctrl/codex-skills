# 0.1.0-preview.3

The complete eight-file `external-ai-team` Skill adds exact-chat master/provider policy checks for Agy, Muse and Claude, canonical/legacy compatibility, metadata-only offline reads, and one explicitly enabled visible console start with pending/unknown deduplication. Current-chat browser-first selection, project conversation reuse, drafts, model choices and saved pauses remain effective. Multiple eligible providers never imply broadcast.

Install `external-ai-team-0.1.0-preview.3.zip` with `python3 external-ai-team/install.py`, optionally selecting `--codex-home`. All eight files and MIT license are included. Existing destinations are refused; configuration, AGENTS, other Skills and permissions are preserved. An update requires backing up the previous Skill outside the discovery directory before an intentional replacement.

Panel switches, the offline policy and configured launcher need a compatible Agy Console. The Skill alone does not install that application or three website clients. Keep this release paired with the matching complete panel package; use the final GitHub Release for the actual paired version and verification. Existing public Agy preview.8 bootstrap does not accept the new panel module, so a compatible full package is required before that panel update.

Automatic console start is disabled by default. Only an active task, exact-chat master+Agy+auto-start permission, verified installation, valid user-configured regular launcher and confirmed-offline service permit one visible terminal attempt. Unknown/pending attempts are not blindly retried. No daemon, LaunchAgent, login, credential transfer, paid action or idle-Codex wakeup is added. Linux supports read-only service status, not automatic terminal start. Real cold start, native Windows terminal and Muse/Claude web delivery remain unverified.

The existing project-memory Skill stays byte-identical to preview.1 and its original ZIP is retained. The collection source ZIP includes all public files and 84 tests: 26 existing project-memory checks plus 58 collaboration policy/startup/parser-integration/installer checks. CI runs macOS/Linux with Python 3.9 and 3.13. All native launchers and host services are replaced with test boundaries; tests do not establish real cross-site delivery. Accurate-commit CI, archive hashes, draft downloads and isolated installs are recorded only after verification. Local adapters, live configuration, screenshots, checkpoints and raw AI results are excluded.
