# 0.1.0-preview.2

Adds the complete `external-ai-team` Skill: current-chat browser-first provider selection, project conversation reuse, draft and pause preservation, actual-result verification, an optional generic Antigravity reference, metadata, an explicit installer and MIT license. Explicit user choices take precedence over the confirmed selected project AI page, followed by this chat's saved provider/conversation. A page or response supplies no new permissions.

Install from `external-ai-team-0.1.0-preview.2.zip` with `python3 external-ai-team/install.py`, optionally passing `--codex-home /path/to/codex-home`. Existing destinations are refused; configuration, AGENTS and other Skills are preserved. Installing the Skill does not install a service, log in, grant transmission permission, start background work or guarantee discovery by every existing chat. A supported host browser tool and an authorized AI destination are required for browser collaboration.

The existing `codex-project-memory` source and helper remain unchanged. Its complete `codex-project-memory-0.1.0-preview.1.zip` is included with its original bytes; the collection version advances to preview.2. The full source archive is `codex-skills-0.1.0-preview.2-source.zip`. All three ZIPs carry the appropriate MIT license; `SHA256SUMS` covers them.

The behavior suite contains the existing 26 project-memory tests plus four installer checks for the new Skill. CI runs macOS/Linux with Python 3.9 and 3.13. Format and static scenario review do not establish real multi-provider browser delivery, native Windows support or automatic discovery in old chats. Final exact-commit CI, archive hashes, draft/public download and isolated installation verification are recorded in the GitHub Release only after those checks run. Local adapters, private data, backups and review logs are excluded. Agy/Bark software and prior tags/assets retain their existing releases.
