# 0.1.0-preview.1

Includes the complete `codex-project-memory` skill, a revision-checked POSIX helper, schema documentation, an explicit installer and isolated behavior tests. The standalone Skill archive retains its MIT license and all relative references.

Download `codex-project-memory-0.1.0-preview.1.zip` for installation or `codex-skills-0.1.0-preview.1-source.zip` for source and tests. Install from the extracted directory with `python3 codex-project-memory/install.py`. Existing destinations are refused; no instruction files or real project data are replaced.

Python 3.9+ on macOS/Linux is supported; native Windows is not. Final exact-commit CI, archive hashes and public download/isolated install verification are recorded in the GitHub Release after those checks run. Private state and review logs are excluded. This release does not train a model, schedule recovery or measure token savings.
