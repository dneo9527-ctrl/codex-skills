# Antigravity 适配

只在本轮已选择 Ag 控制台时读取。通用浏览器优先路由在主 Skill 中；本参考不改变它。

从已安装控制台的受支持部署说明、当前项目指令或用户明确提供的路径定位 dispatcher，核实该文件存在后使用；不要遍历全盘或猜安装目录。复用它和官方 CLI 登录。读取 dispatcher 返回的当前聊天绑定、`multi_ai_collaboration`、`auto_open_activity`、`panel_action`，按[开关约定](collaboration-controls.md)核对总控与Agy；旧服务才使用`collaboration_enabled`。正常绑定不能重新开启已关闭的开关。没有部署说明或可用适配器时，使用已打开且授权的 Ag 网页 UI，或标记协作未执行，不假设某个端口、路径或后台服务存在。

`CODEX_THREAD_ID` 决定当前聊天身份。一聊天沿用一个固定入口和主 Ag 会话；只有确需独立上下文才在同入口中使用稳定命名分支。不要根据标题、cwd、最新会话或输出目录选择 Ag ID。

普通派发不强制模型，保留当前窗口文字/生图模型及速度设置。额度不足时遵循已配置的候补和实际可用模型；不反复切换同额度组、自动换账号、购买或开启付费超额。

允许自动显示时，复用本聊天 Ag 标签并显示实际活动。`panel_action` 是请求，不证明已可见；关闭自动显示时不自动打开、导航或跟随。不为展示 Ag 覆盖另一已选 AI 页面，不改草稿。

显现使用宿主/浏览器已公布的能力，并核对准确固定 URL、选中标签与当前任务。宿主 `queued`、标签可截图、页面正文已更新都不证明用户正在看见它；浏览器可见也不证明操作系统窗口在前台。显现请求可能异步生效，单次请求后立即 `false` 先记待核对，在活跃任务内给一次短观察窗（例如总计 5 秒、最多两次只读检查），不重复发送显现请求或创建新标签。窗内仍未证实则报告“活动页已准备，自动展开未确认”并给原固定链接；不无限等、不再次调用模型测试。若用户明确确认本次页面已经展开，而工具仍返回 `false`，保留两份证据，将该次实际展开记为用户确认、工具可见指标不一致，不能据此反说用户没看到或重开页面；准确任务和会话仍须独立核验。仅检查到本就已打开的 `true` 不算收起后自动恢复验收。自动协作不授权切换用户当前 Codex 聊天、导航或刷新抢焦点；用户明确要求展示本聊天时才可使用受支持导航，且导航回执也须另验显示。

圆桌会议的显现目标应关联准确 `meeting_id`。支持会议目标的 bridge 会在新会议创建或 Agy 会议派发中返回包含 `meeting` 参数的固定 URL；首次无标签时仅创建这一页。已有本聊天固定页时优先沿其活动跟随就地进入本场，核对本场标题和各方真实发言；不要因 URL 多了会议参数就反复新开或刷新。已有草稿、历史阅读或另一场手动焦点时保留用户选择，报告目标已准备。查询、普通事件同步和幂等会议恢复不要求再次显现；Muse 网页沿用本项目原会话，真实回复同步到本场，不能用本地代写替代。

提交后核对真实任务 ID、完成状态、非空结果和持久会话 ID。超时先检查原任务；不得当作失败而重发。控制台支持 `collaboration_results` 时，用真实 turn ID 回填接受/拒绝/暂缓与实际检查；未支持时保留本地证据并标记未回填。

控制台未运行时按[启动约定](collaboration-controls.md)读取离线策略与用户配置的正规入口；自动启动明确允许才调用helper。官方认证过期让用户走官方登录，不读取或转移凭据。

本机部署若提供额外适配文档，只在当前主机使用；它不属于此通用版本的授权或依赖。
